# ADR-0013: MCP server as a first-class host

- Status: Proposed
- Date: 2026-09-03

## Context and decision
The company is AI-forward: expose the game as MCP tools (Streamable HTTP + stdio) using the official C# SDK. The MCP host calls the API over HTTP with a service token (thin adapter that respects API auth) and runs simulations locally with the Domain package.
